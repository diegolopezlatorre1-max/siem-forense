nohup pnpm --filter api start:worker > ~/worker.log 2>&1 &
nohup pnpm --filter web dev --host   > ~/web.log    2>&1 &

================================================================
  SI ALGO FALLA  (resumen)
================================================================
Agente da 401          -> Llave mal tecleada. Copia/pega, verifica con echo.
Agente "No conecta"    -> API de Ubuntu apagada. Repite FASE 1.
Agente da 404          -> API reiniciandose/mal arrancada. Repite FASE 1, confirma con curl health.
Web no cambia          -> Ahora refresca sola cada 4 s. Si no, boton "Buscar".
"nuevas":0             -> La alerta ya existia (antiduplicados). Borrala y reataca.
PowerShell "scripts deshabilitada" -> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Bypass -Force
net user "ya existe"   -> Usa otro nombre (backdoor6...).
agente:crear "agentes_nombre_key" -> Nombre repetido. Usa otro o reutiliza la llave.
agente:crear con < >   -> NO se escriben los corchetes.
"New-NetFirewallRule not found" -> Lo lanzaste en KALI. Es de WINDOWS.
Kali SMB "IO_TIMEOUT"  -> Firewall SMB sin abrir. nc -zv 192.168.56.102 445
smbclient "not found"  -> sudo apt install smbclient
ping a Windows falla   -> Normal (ICMP). Usa Test-NetConnection 192.168.56.101 -Port 3000
Ver alertas en crudo:
  docker compose exec -T postgres psql -U siem -d siem -c "SELECT regla_id, clave, cantidad, creada_en FROM alertas ORDER BY creada_en DESC LIMIT 5;"
